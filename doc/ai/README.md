# AI Onboarding Documentation

This directory is the durable onboarding set for AI coding agents and human contributors working in the Spall repository.

It is evidence-backed: claims should point to source files, tests, manifests, CI, or current docs. When evidence is weak, label it as `Strong inference`, `Hypothesis`, or `Open question` instead of making it sound settled.

Start with [00_READ_THIS_FIRST.md](00_READ_THIS_FIRST.md), then choose the task-specific document:

- Architecture and boundaries: [10_ARCHITECTURE.md](10_ARCHITECTURE.md)
- Repo layout: [20_PROJECT_MAP.md](20_PROJECT_MAP.md)
- Rules: [30_DESIGN_RULES.md](30_DESIGN_RULES.md)
- Repeated patterns: [40_COMMON_PATTERNS.md](40_COMMON_PATTERNS.md)
- Commands: [50_TESTING_AND_COMMANDS.md](50_TESTING_AND_COMMANDS.md)
- Performance-sensitive areas: [60_PERFORMANCE_NOTES.md](60_PERFORMANCE_NOTES.md)
- Terms: [70_GLOSSARY.md](70_GLOSSARY.md)
- Uncertainty: [80_OPEN_QUESTIONS.md](80_OPEN_QUESTIONS.md)
- Local guidance plan: [90_LOCAL_AGENT_PLAN.md](90_LOCAL_AGENT_PLAN.md)
- Architecture/change memory: [AI_CHANGELOG.md](AI_CHANGELOG.md)

These docs complement, not replace, root [AGENTS.md](../../AGENTS.md), local crate `AGENTS.md` files, user docs in `docs/src/`, and design history in `docs/internal/`.
